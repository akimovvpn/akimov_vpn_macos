# macOS Port Implementation Plan

**Goal:** Build a macOS counterpart of akimov_windows using the same patched Mihomo core.
**Architecture:** Reuse UI and portable Rust modules. Replace Windows integration with macOS platform modules and keep privileged runtime files root-owned.
**Tech stack:** Tauri 2, Rust, static JavaScript/CSS, Go Mihomo.
**Spec:** docs/superpowers/specs/2026-11-14-macos-design.md

- [x] Port OS modules: process supervisor, launchd broker, SystemConfiguration proxy recovery, hardware UUID and Keychain. Preserve validation and add platform regression tests.
- [x] Update app lifecycle, resource discovery, profile headers, TUN config and macOS wording. Retain account and UI tests; replace Windows-only lifecycle tests with isolated macOS checks.
- [x] Add pinned core/native app build scripts, icons, Apple Silicon/Intel CI and release documentation. Preserve all four patches and provenance hashes.
- [x] Run Rust tests/lint, UI checks, real-core failover, package .app/DMG, and inspect artifacts. Document untested privileged networking and signing requirements.

Review focus: unauthorized IPC peers; untrusted YAML paths or hooks; interrupted proxy writes and other apps taking ownership; app death leaving cores alive; missing/wrong-architecture bundle resources. All checks must avoid altering the user's active networking.

Review: a separate reviewer found TUN stop errors were swallowed. Normal disconnect now reports recovery failures; the helper retains its lease and retries until network preferences are restored. Remote-provider file accesses were checked against the pinned Mihomo safe-path implementation.

Build: Rust 1.97 stripping proc-macro dylibs creates LINKEDIT alignment failures on macOS 27. Disable stripping only in release.build-override, preserving the stripped shipped executable.

Completed validation: 49 Rust tests passed, 2 opt-in tests ignored; clippy and formatting clean; fixture UI and rendered UI passed; native Mihomo REALITY/Vision Chrome/Firefox and selection/failover passed; normal pipe close and forced parent termination stopped real cores. Apple Silicon .app/DMG built, native WKWebView sign-in visually verified, ad hoc signature and disk-image checks verified. Privileged TUN/proxy/DNS and Keychain integration, Intel runtime, signing/notarization credentials and release hosting remain outside this local acceptance run.
